# Next evaluation cycle — not yet conducted

Recruit 3–5 consenting multilingual readers with mixed familiarity with Wikipedia. Do not treat this small convenience sample as representative of all readers. Avoid collecting names or private browsing history.

Ask each participant to think aloud while performing:

1. Tell us which language a search will use before submitting it (R1).
2. Find Urdu starting from the home screen (R2/R3).
3. Find a different non-featured language by its English or native name (R2).
4. Return from language selection without losing a draft query (R4).

Use the original portal for a baseline. The redesign is currently static: use a facilitator to simulate the specified screen changes, or build clickable states first. Do not record static wireframe clicks as functional search success. Alternate presentation order to reduce learning effects.

Record task completion, wrong turns, assistance, time, and a 1–5 ease rating. Proposed goals (not achieved results): at least 80% unassisted language-discovery completion, no unintended language switches, and lower median completion time than baseline. With 3–5 people, report raw counts and individual observations alongside percentages.
